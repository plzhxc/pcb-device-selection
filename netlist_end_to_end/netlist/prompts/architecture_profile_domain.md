A profile domain requires all three: an existing board.static_environment source ID, voltage_v=null, and an explicit reference to its actual return domain. A null scalar preserves the source range; it does not waive the reference. Use the reported selected fields to identify what failed. Declare any needed return domain only from supplied evidence; a domain name or 0 V does not prove a common return. Do not guess a reference, substitute a nominal voltage, or drop the profile to bypass this check.
